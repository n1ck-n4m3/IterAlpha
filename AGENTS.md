# Project language conventions

- Write source code, code comments, identifiers, filenames, configuration, tests, logs, and technical error messages in English.
- Use English for product interface copy, authored training content, and runtime AI instructions. Keep interface copy centralized for possible future localization.
- Owner-facing development prompts, plans, explanations, and operating manuals may be written in Chinese. Keep their filenames in English.
- Preserve the original wording of external source material when required for provenance or quotation.
- Apply these conventions to new and edited work. When implementing the MVP, migrate existing Chinese product copy to English.
