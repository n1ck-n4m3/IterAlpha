# Spider 可视化驾驶舱

日期：2026-10-29。本次重做 Spider 的前端信息架构和视觉交互，保留现有规则策略、虚拟本金、服务端账本、行情许可边界和账户历史。主页、训练、复盘和进度入口继续存在。

## 新版的阅读顺序

- 顶部：币种、最新价格、实际记录的迷你走势、模拟盈亏、净值、回撤和已平仓胜率。没有样本时显示空值。
- 左侧：实时行情大图，保留图表类型、MA、EMA、Bollinger、成交量、MACD 和 RSI。持仓存在时可以显示实际入场、止损和止盈价格线。
- 右侧：蜘蛛在四个圆柱节点间移动。Observe 读取报价与盘口；Decide 表示规则判断；Guard 表示代码检查；Execute 表示最终模拟成交或等待。
- 下方：资金占用环、盘口深度柱、买卖深度比例，以及可拖动、可播放的历史检查时间轴。
- 完整策略说明、交易记录、证据、账户和连接信息移入弹层；首屏保留执行状态、虚拟资金和数据可信度标签。

参考了 [Jev Trade](https://github.com/aowang-ai/jev-trade) 的“市场图 / 决策 / 账户”分区，以及 [jev-trader](https://github.com/jarrodwatts/jev-trader) 区分决策和成交的事件记录方式。视觉和交互为本项目重新实现，没有复制第三方界面源码。

## 动画的含义

蜘蛛的四阶段路径是对最新已保存检查的可视化播放，界面标注 Last check 和时间；它不表示客户端看见了服务器内部的逐毫秒执行，也不表示模型已调用。新检查到达才会重新播放路径；真实行情读取期间可以点亮观察节点。

- 紫色路径与节点：规则检查与等待；青色：行情读取；粉色：拦截；绿色：通过或实际纸面成交。
- Buy / Sell 和成交确认闪光只来自账本中的实际模拟结果，不从规则提议推断。
- 拖动时间轴或点击播放后，蜘蛛区明确标注 Recorded check / Replay。行情图与当前深度仍然是实时视图，不伪造旧时刻的盘口或未保存的 K 线过程。
- 暂停停止策略循环的视觉播放；断流显示 No fresh feed。背景波浪属于装饰，与价格、收益和推理无关。
- Motion 开关关闭背景渲染循环、节点动画、数字插值和新增蜡烛的过渡。初始状态遵循系统减少动态效果的偏好。隐藏页面会暂停背景渲染。

## 操作

1. 直接 Deploy Spider 使用默认虚拟本金和策略；可点击 Strategy 打开策略卡片、金额、分配比例与退出设置。
2. 已有账户的策略和币种保持固定；暂停后选择 New spider，创建一个新的配置草稿，旧账本保留。
3. 点击任一阶段、结果或 Evidence 查看依据。旧检查没有输入快照时不会借用当前数据。
4. Paper ledger 查看成交与记录的净值，保留导出。Accounts 可切换旧账户。

## 验证与实现

- React / TypeScript；原生 WebGL 背景、SVG 蜘蛛与节点、CSS 动效；实际行情继续使用 Lightweight Charts。没有新增第三方动画依赖或服务费用。
- 动画背景限帧并处理销毁、隐藏和 WebGL 不可用情形，保留 CSS 背景作为回退。
- 自动测试增加回放与实时状态分离、断流/暂停状态、被拦截买入不显示成交、旧记录缺失证据和迷你曲线输入校验。
- 浏览器检查桌面和 390px 内嵌视口、策略切换与分配滑块、换币、暂停、历史播放、关闭动态效果、弹层与证据。390px 是响应式预览，不是实体手机测试。

当前没有真实交易所资金、没有运行中的 AI 模型，也没有新增历史盘口数据。前端动画不构成盈利证据。
