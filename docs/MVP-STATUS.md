# MVP 实际交付状态

更新日期：2026-10-27（美国东部时间）。

| 项目 | 状态 |
| --- | --- |
| Play 与新场景 | 每次 Play 从随机种子生成新的 BTC/ETH、趋势/区间/波动场景；旧六题保留以便回看已有记录 |
| 自定虚拟本金 | $100–$1,000,000，默认 $10,000；每轮独立账户，收益率按该轮本金计算 |
| 决策节奏 | 可选 15 分钟、1 小时或 4 小时信息节点；新手 6 次、进阶 8 次决策，节点不强迫交易 |
| 买入、加仓与现金 | 滑块选择美元金额或现金比例；输入金额是扣款上限；剩余现金可继续买，卖出可释放现金 |
| 止损与风险解释 | 保护性止损可能触发卖出；风险百分比是按止损估算的账户损失占比，超过 2% 仅提示，不自动交易，也不硬性拦截 |
| 成交与复盘 | 下一根开盘、费用、滑点、止损、现金上限由程序计算；显示实际扣款和逐步复盘，不把事后对照冒充 EV |
| 图表 | 15m/1h/4h，可切换十种常用时间图表样式；Heikin Ashi 是显示转换，成交用原始价格 |
| Market | BTC/ETH/SOL/XRP 站内合成报价卡和图表默认展开；不是实时或历史行情，未接入真实数据授权 |
| 会话与日志 | 后端隐藏未来、会话隔离、幂等请求、刷新恢复、Review / Progress 与 JSON 导出 |
| 新手教程与教练 | 首轮附 60 秒教程；每次决策后展示实际金额、仓位与止损风险、规则反馈和三个可点开的追问。真实模型接入代码已具备；目前无 API key，卡片明确标注预览，不冒充真实 AI |
| 真实历史行情 | 适配器和导入校验已具备，但没有已确认可用于训练回放的授权历史数据；新 Play 仍为模拟行情 |
| 玩家 Rank、实时模拟交易、美股 | 尚未上线；公平对战规则、授权实时数据、独立虚拟账本与跨资产结算仍需下一阶段开发 |

目前站点已公开供持链接的测试者访问：[打开 IterAlpha Training](https://iteralpha-training.natez0772.chatgpt.site)。Market 的合成报价不等于训练盘的成交来源；任何真实交易功能都未接入。
