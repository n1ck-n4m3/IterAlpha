# IterAlpha 演示与使用手册

## 体验一轮

1. 打开网站后点击 **Play**。每次点击会生成一条新的 BTC 或 ETH 模拟行情；页面刷新不会丢掉未完成的一轮，可以点 **Resume unfinished round** 继续。原来的六个固定教学场景仍可用于旧记录回看，不再是新用户的唯一题库。
2. 输入自己的初始虚拟本金，默认 **$10,000**，范围 **$100–$1,000,000**。选币种（或随机）和 **1 小时 / 4 小时** 的下一决策节点。节点是练习中的信息更新节奏，并不是“每隔几小时必须买卖”；空仓可 Wait，持仓可 Hold。
3. 阅读截止时刻前的图表和 **Fact / Inference / Unknown**。未来价格不会在决策前发给浏览器。图表可切换 15m、1h、4h 周期，以及普通 K 线、空心 K 线、OHLC/HLC 柱、折线、带点折线、阶梯线、面积、基准线与 Heikin Ashi，共十种常用样式。Heikin Ashi 是平滑显示价，实际成交与复盘仍用原始 OHLC。
4. 买入时直接输入 **美元金额**，也可用剩余现金的 10%、25%、50% 或 Max。默认建议首次只用约四分之一现金，给后续加仓留空间。预览会显示预计扣款、币数、剩余现金和“按止损价估算可能损失的金额与账户占比”。这个风险百分比**只是说明，不会自动买入或卖出**；真正可能触发自动卖出的是单独填写的 **Protective stop price**。超过 2% 会提醒，但不会隐藏地拦截买入。
5. 点击 **Confirm & reveal** 后，市场单按下一根开盘价加手续费与滑点模拟成交。输入的美元金额是**实际扣款上限**；价格跳动时币数会调整。若首次花光本金，下一阶段仍有 Buy 入口，但须先卖出或减半释放现金，才能再次买入。已持仓时可以用剩余现金继续加仓，原止损保持不变。
6. 三次决策后查看每笔实际花费、费用、净结果与逐步复盘。逐步对照只比较同一条已经发生的路径，**不等于统计意义的预期收益 EV**。没有 AI 密钥时页面明确使用规则反馈。在 **Review** 查旧记录，在 **Progress** 看完成次数与不同情境的训练分布。

## Market 页面

打开 **Market** 就直接显示 BTC、ETH、SOL、XRP 的 Coinbase Exchange 最新成交报价和默认 BTC 图表，不需要展开外部组件。点击币种卡片切换图表，报价可经公开行情流持续更新，接口也会定期刷新；页面显示每条报价的成交时间。图表历史与最新成交价可能略有时间差。此页只供观察，**不会拿实时报价给训练盘结算**；训练盘仍用明确标注的合成行情和虚拟本金。

若外部行情暂时不可用，页面会显示不可用状态，不会编造价格。真实实时模拟交易需要另外定义数据使用许可、报价过期判定、成交规则与独立账本。

## 三分钟展示

- 0:00–0:30：打开 Play，设置虚拟本金和 1 小时或 4 小时节点，强调新场景每次不同。
- 0:30–1:20：先看信息，再用 $2,500 买入；指出风险百分比与止损触发价是两回事。
- 1:20–1:55：看实际扣款与剩余现金，第二次 Buy 加仓，或 Hold 等待。
- 1:55–2:25：切换图表样式，完成第三个节点，展示逐步复盘与成本。
- 2:25–3:00：进入 Market，看四个币种的当前报价和站内图表，说明模拟练习与实时行情的边界。

## 邀请测试者

当前站点保持 **仅所有者可访问**。远程测试者须在站点访问设置中被单独加入，不要仅转发 URL 并假设对方能进入。每位测试者的记录彼此隔离；站点不要求交易账户，也不会下真钱订单。观察他们能否自行完成第一轮、理解金额与风险、愿不愿意再点一次 Play。
